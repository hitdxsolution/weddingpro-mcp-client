# WeddingPro 직원 커넥터

Claude에서 커넥터를 연결하면 브라우저에 WeddingPro 로그인 화면이 열립니다. **직원 계정**으로 로그인하고 Claude로 돌아오면 조회 도구를 사용할 수 있습니다.

비밀번호는 WeddingPro 로그인 화면에 입력합니다. 토큰 저장과 갱신은 클라이언트가 처리합니다. 계정을 바꾸거나 접근을 끝내려면 클라이언트의 커넥터 설정에서 연결을 해제한 뒤 다시 연결하세요.

직접 연결 주소는 `https://pro.villadegd-server.click/mcp/employee`입니다. 개발 서버를 검증할 때는 클라이언트 설정에서 호스트를 `dev.villadegd-server.click`로 지정합니다.
