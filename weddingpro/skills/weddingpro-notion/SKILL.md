# Notion 자료 가져오기

회사 자료(매뉴얼, 정책, 회의록, 기획서 등)는 Notion에 있다. 아래 절차로 **항상 검색해서** 가져온다.

## 철칙: 하드코딩 금지

- 페이지 ID, 페이지 URL, 워크스페이스 도메인을 **외우거나 저장해서 재사용하지 않는다.** 자료 위치와 구조는 수시로 바뀐다.
- 이전 대화나 메모리에 남아 있는 Notion 링크도 신뢰하지 말고, 매번 검색으로 현재 위치를 다시 찾는다.
- 답변에 출처 링크를 붙이는 것은 좋다 — 단, 그 링크는 **방금 검색/조회 결과에서 받은 것**이어야 한다.

## 절차

### 1. Notion 도구 로드

Notion 도구는 지연 로드(deferred) 상태일 수 있다. 먼저 도구를 찾는다:

- Claude Code: `ToolSearch`에 `notion` 키워드로 검색해 도구 스키마를 로드한다.
- 도구 이름은 환경에 따라 다르다 (예: `mcp__claude_ai_Notion__*` 형태). 이름을 추측하지 말고 검색 결과에 나온 이름을 쓴다.

### 2. (필요 시) 인증

검색/조회 도구 없이 `authenticate` 류 도구만 보이면 아직 연결 전이다:

1. `authenticate` 도구를 호출해 승인 URL을 받는다.
2. URL을 사용자에게 전달하고 브라우저에서 Notion 계정으로 승인하게 한다.
3. 승인 후 브라우저 주소창의 callback URL(`http://localhost:<port>/callback?code=...`)을 받아 `complete_authentication`에 넘긴다. (페이지가 안 떠도 주소창의 URL은 유효하다)
4. 완료되면 실제 검색/조회 도구가 자동으로 나타난다.

claude.ai 웹/데스크톱에서는 설정 → 커넥터에서 Notion을 연결하면 된다.

### 3. 키워드로 검색

- 사용자가 쓴 표현 그대로 + 핵심 단어만 줄인 버전으로 **한국어 키워드 검색**을 한다.
- 한 번에 안 나오면: 동의어(예: "매뉴얼" ↔ "가이드" ↔ "사용법"), 더 짧은 키워드, 관련 업무 용어로 2~3회 바꿔 검색한다.
- 결과가 여러 개면 제목·수정일·상위 페이지를 보고 고르고, 애매하면 후보를 사용자에게 보여주고 고르게 한다.

### 4. 본문 읽기

- 검색 결과의 페이지를 fetch(조회) 도구로 읽는다.
- 본문에 하위 페이지·링크·데이터베이스가 있으면, 결과에 포함된 ID/URL로 **추가 fetch**해서 따라간다. 목차만 읽고 끝내지 말 것.
- 필요한 페이지만 읽는다 — 관련 없는 페이지를 대량으로 fetch하지 않는다.

### 5. 활용·인용

- 답변이나 산출물에 쓸 때는 출처로 **페이지 제목 + 방금 받은 링크**를 표기한다.
- 자료 내용과 사용자 말이 다르면 노션 자료의 수정일을 확인하고, 오래된 자료일 가능성을 함께 알린다.

## 안 될 때

- **검색 결과가 비어 있다**: 권한이 없는 페이지는 검색에 안 나온다. 사용자에게 해당 자료가 Notion 연결 계정에 공유되어 있는지 확인을 요청한다.
- **인증이 풀렸다**: 2번 절차를 다시 수행한다.
- **자료가 정말 없다**: 없는 대로 보고한다. 비슷한 제목의 다른 자료를 근거인 척 쓰지 않는다.
