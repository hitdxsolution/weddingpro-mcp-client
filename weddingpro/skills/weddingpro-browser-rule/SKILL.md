# weddingpro 브라우저 접근 규칙

Chrome 브라우저 확장(브라우저 자동화)으로 weddingpro 에 접근할 때는 아래를 반드시 지킨다.

## 1. 변경 금지 (수정·추가·삭제 금지)

- 어떤 데이터도 **바꾸지 않는다.** 추가·수정·삭제를 하지 않는다.
- POST/PUT/PATCH/DELETE 요청, 저장·등록·수정·삭제·발송·알림톡 등 **변경 동작 일체 금지**.
- 사용자가 "수정해줘 / 지워줘" 라고 명시해도 **이 경로(브라우저)에서는 수행하지 않는다.** "조회 전용입니다. CRM에서 직접 진행해주세요" 라고 안내하고 멈춘다.
- 의도치 않게 변경 동작이 나갔다면 즉시 멈추고 사용자에게 보고한다. **임의 복구·롤백 금지**(롤백도 또 다른 변경이다).

## 2. 조회만 허용

- GET 조회, 페이지 열람, PDF 다운로드(읽기·렌더 동작) 등 **데이터를 바꾸지 않는 동작만** 허용한다.
- 모달·버튼 중에서도 `다운로드`·`보기` 같은 읽기 동작만 누르고, `삭제`·`수정`·`등록`·`저장` 등은 절대 누르지 않는다.

## 3. 반복 작업은 패턴화해서 빠르게

- 같은 작업을 여러 건 반복할 때는 **하나하나 클릭으로 순회하지 말고**, 가장 유사한 패턴(공통 URL·API·좌표·셀렉터)을 한 번 찾아 그 패턴을 반복 적용한다.
- 가능하면 **한 번의 조회로 대상 목록을 확보**(API/목록 GET)하고, 건별 동작을 같은 묶음으로 일괄 처리해 라운드트립을 최소화한다.
- 좌표·셀렉터가 어긋나면 한 번만 다시 확인(screenshot 등)하고, 이후 건부터는 새 패턴으로 진행한다(매 건 확인은 오버헤드).
