# 로그인 안내 (거래처)

로그인이 필요하면 **선택형 질문(AskUserQuestion)** 으로 이메일과 비밀번호를 한 번에 묻는다(거래처 계정).
- 질문1: "이메일" — 사용자가 직접 입력
- 질문2: "비밀번호" — 사용자가 직접 입력

받은 값을 `wedding_pro_login` 의 `email`/`password` 인자로 전달한다.

> 비밀번호는 민감정보다. 입력창(elicitation)을 지원하는 클라이언트라면 `wedding_pro_login` 을 인자 없이 호출해 그 입력창(채팅에 안 남음)을 쓰는 편이 더 안전하다.
