name: weddingpro-setup
description: WeddingPro 거래처 커넥터에 연결되지 않거나 조회 도구가 보이지 않을 때 점검한다.
---

클라이언트가 원격 HTTP MCP 커넥터와 OAuth 로그인을 지원하는지 확인한다. 서버 주소는 `https://pro.villadegd-server.click/mcp/vendor`이다.

커넥터 설정에서 WeddingPro를 연결하고 브라우저에서 거래처 계정으로 로그인하도록 안내한다. 기존 연결이 남아 있으면 설정에서 연결을 해제한 뒤 최신 플러그인으로 다시 연결하도록 안내한다.
