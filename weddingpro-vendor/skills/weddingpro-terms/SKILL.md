# 웨딩프로 용어/관점 (거래처)

이 커넥터는 **거래처(vendor) 입장**의 조회 도구를 제공한다. 직원용 도구(미팅 일정·홀일정 등)는 보이지 않는다.

## 관점

- 로그인한 **거래처 본인** 권한으로, 자신에게 연결된 데이터만 조회된다.
- 노출 도구는 **GET 조회**(거래처 로그인·public)만. 변경/관리자 기능은 없다.

## 용어

- **거래처 (vendor)** = 로그인한 협력 업체(=나).
- **고객 (client)** = 거래처와 연결된 고객.
- **발주 / 주문 (order)** = 거래처에게 들어온 발주.

## 로그인

조회 전 반드시 `wedding_pro_login` 으로 **거래처 계정**으로 로그인한다. 미로그인 시 401. 직원 계정과는 별개다.
